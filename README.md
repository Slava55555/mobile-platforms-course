## Структура проекта

```
mobile-platforms-course/
├── console-apps/                       # Модуль: Создание консольных Java-приложений
│   ├── Matching-password/              # Подбор пароля с CRC32
│   ├── shopping-list/                  # Список покупок
│   ├── Inheritance/                    # Разработка классов с интерфейсом Comparable
│   ├── Stepik-robot/                   # Реализация класса для управления роботом
│   ├── Analysis-play-by-roles/         # Разбор пьесы по ролям
│   └── City-app/                       # Приложение для выбора города с наиболее тёплой погодой
├── android-basics/                     # Модуль: Разработка для ОС Android
│   ├── add-two-numbers/                # Приложение для сложения двух чисел
│   ├── marking-for-booking-flights/    # Разметка приложения для бронирования авиабилетов
│   ├── random-movie/                   # Приложение "Случайный фильм" 
│   ├── guess-the-num/                  # Игра "Угадай число"
│   ├── arrayAdapter/                   # Работа с ArrayAdapter
│   ├── listViewPracticum/              # ListView практикум (разработка собственного адаптера)
│   └── memory/                         # Игра "Меморина"
└── README.md                           # краткое описание репозитория
```
